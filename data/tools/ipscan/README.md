# InterProScan

### Installation
You can download InterProScan from their website https://www.ebi.ac.uk/interpro/download/InterProScan/.

### Usage
We use InterProScan to predict the domains of our transcription factor sequences. You can run `scripts/get_domains.py --dataset cisbp --fold-dirs <af3_output_dir>` to get the predicted domains for proteins in our cisbp dataset.
